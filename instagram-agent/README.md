# وكيل النشر على إنستقرام — @batagonun

هذا الملف هو المرجع الثابت للوكيل. أي جلسة جديدة أو مهمة مجدولة تقرأه أولًا قبل إعداد أي دفعة بوستات.

## 1. الحساب وأداة الجدولة
| البند | القيمة |
|---|---|
| الحساب | إنستقرام `@batagonun` (ولينكدإن مربوط ولا يُستخدم حاليًا) |
| أداة الجدولة | Metricool، رقم البراند `7154737`، المنطقة الزمنية `Africa/Cairo` |
| وقت النشر الافتراضي | 09:00 صباحًا بتوقيت القاهرة، ما لم تُظهر بيانات «أفضل وقت للنشر» في Metricool وقتًا أفضل |
| الإيقاع | 4 بوستات أسبوعيًا تقريبًا |

## 2. قاعدة المراجعة (إلزامية)
- **لا يُجدول أي بوست على Metricool قبل موافقة صريحة من المستخدم.**
- كل دفعة تُعرض أولًا في صفحة مراجعة تتضمن الصورة والكابشن والموعد والمحور، ثم تُجدول بعد الموافقة فقط وبالتعديلات المطلوبة.

## 3. محاور المحتوى
| المحور | اللغة | التكرار | ملاحظات |
|---|---|---|---|
| مناسبات وأعياد المجتمع المصري | عربي | حسب التقويم | الأولوية للمناسبة إن وُجدت في الأسبوع، بلغة وقورة ومحايدة |
| حكمة الأسبوع (Weekly Wisdom) | **إنجليزي** | **أسبوعيًا (الأحد)** | أقوال عميقة **موثّقة النسبة** مع ذكر المصدر، وتأمل قصير وسؤال |
| عادات سليمة بين الزوجين | عربي | 1–2 أسبوعيًا | سلوك عملي واحد قابل للتطبيق، دون وعظ أو تعميم |
| عادات صحية | عربي | 1 أسبوعيًا | دون ادعاءات طبية مبالغ فيها، وتُربط بالأيام العالمية متى أمكن |
| شعر وحكمة عربية | عربي | 1 كل أسبوعين | أبيات صحيحة النسبة ومضبوطة بالشكل |

## 4. معايير الجودة
1. **التحقق من النسبة:** لا يُنشر قول مأثور منسوب خطأً، مثل الأقوال الشائعة المنسوبة إلى جلال الدين الرومي أو أرسطو دون مصدر. يُذكر الكتاب أو الرسالة دائمًا.
2. **التفاعل:** كل كابشن ينتهي بسؤال أو دعوة إلى الحفظ أو المشاركة، مع 4 هاشتاجات كحد أقصى.
3. **الصور:** مقاس 1080×1350 (4:5)، وتصميم معبّر عن الفكرة لا مجرد نص على خلفية، مع هوية بصرية متسقة وتوقيع `@batagonun`.
4. **الحساسية:** مراعاة الأعراف الدينية والاجتماعية المصرية، وتجنّب السياسة والجدل.

## 5. الأدوات (مجانية بالكامل)
| المرحلة | الأداة | الترخيص |
|---|---|---|
| التصميم والإخراج | HTML/SVG، ثم تحويله إلى صورة عبر Chromium وPlaywright (`tools/render.mjs`) | مفتوح المصدر |
| اللمسات النهائية (حبيبات وتظليل حواف وتصدير JPEG) | Pillow (`tools/finish.py`) | مفتوح المصدر |
| الخطوط | Amiri وCairo وCormorant Garamond من Google Fonts (`fonts/`) | SIL Open Font License |
| بدائل اختيارية | Canva Free وAdobe Express Free وGIMP | مجانية |

تُعرَّف الصور ذاتيًا دون صور مخزون، فلا توجد مخاطر حقوق ملكية.

```bash
node tools/render.mjs posts/<batch>.json out/<batch>
python3 tools/finish.py out/<batch>
```
بعد الدفع إلى GitHub تصبح الصور متاحة لـ Metricool على الرابط:
`https://raw.githubusercontent.com/batagonun/hotel/<branch>/instagram-agent/out/<batch>/<id>.jpg`
