# تشغيل المحطة على هاتف المشرف (بدل كمبيوتر المكتب)

الفكرة: هاتف المشرف يشغّل خادم الإدارة نفسه، ويفتح نقطة اتصال (Hotspot). يتصل المفتشون بها في موقع المنشأة، فيستلمون التكليفات ويسلّمون تفتيشاتهم دون الحضور إلى المكتب.

> **تنبيه:** هذا الإعداد لم يُجرَّب بعد على هاتف فعلي. الخادم نفسه اختُبر على نظام لينكس (أساس Termux) ونجحت اختباراته كلها. جرّبه أولاً مع مفتش واحد، مع بقاء كمبيوتر المكتب جاهزاً احتياطياً.

## أولاً: الإعداد لمرة واحدة (نحو 15 دقيقة)

1. ثبّت **Termux** من متجر **F-Droid** (نسخة متجر Google Play قديمة ولا تعمل جيداً).
2. افتح Termux واكتب:
   ```
   pkg update -y && pkg install -y python
   termux-setup-storage
   ```
   ووافق على إذن الوصول إلى الملفات.
3. انقل من كمبيوتر المكتب إلى الهاتف (بالكابل) المجلد `D:\W\نظام_التفتيش` كاملاً، بما فيه `app` و`server` و`بيانات`، وضعه في مجلد **Download**.
4. في Termux:
   ```
   cp -r ~/storage/downloads/نظام_التفتيش ~/
   ```

## ثانياً: في كل جولة

| الخطوة | المشرف | المفتش |
|---|---|---|
| 1 | يفتح نقطة الاتصال، ويعطّل خيار إيقافها تلقائياً من إعداداتها | |
| 2 | يفتح Termux ويكتب:<br>`termux-wake-lock`<br>`cd ~/نظام_التفتيش/server && python server.py` | |
| 3 | يفتح تطبيق التفتيش ← «الاتصال بالإدارة» ← «إدخال العنوان يدوياً» ← يكتب `127.0.0.1` ← «طلب اتصال». يُعتمد تلقائياً لأنه على الجهاز نفسه | |
| 4 | يعيّن القوائم من تطبيقه كالمعتاد، فتُرسَل إلى المحطة تلقائياً | يتصل بنقطة اتصال المشرف |
| 5 | | يفتح التطبيق ← «البحث عن خادم الإدارة» ← «طلب اتصال» |
| 6 | يفتح **Chrome** على `http://127.0.0.1:8770/admin` ويضغط «اعتماد» لكل مفتش | يستلم التكليفات ويبدأ التفتيش، ويعمل دون اتصال |
| 7 | في نهاية الجولة يعيد الاتصال نفسه | يتصل مرة أخرى فتُرفع تفتيشاته تلقائياً |

## ثالثاً: نقل البيانات إلى كمبيوتر المكتب

البيانات المستلمة تُحفظ على هاتف المشرف في `~/نظام_التفتيش/بيانات`، ونسخة مقروءة لكل نادي في `~/نظام_التفتيش/الأندية`. انقلها إلى الكمبيوتر بانتظام:

```
cp -r ~/نظام_التفتيش/بيانات ~/نظام_التفتيش/الأندية ~/storage/downloads/
```

ثم انسخها بالكابل من Download إلى `D:\W\نظام_التفتيش\` و`D:\W\` على الكمبيوتر.

## مشكلات محتملة

| المشكلة | الحل |
|---|---|
| المفتش لا يجد المحطة بالبحث | يكتب عنوانها يدوياً. يظهر العنوان في Termux عند تشغيل الخادم («عنوان الخادم على الشبكة») وفي أعلى لوحة الاعتماد |
| بعض الهواتف تمنع الأجهزة المتصلة بنقطة الاتصال من الوصول إلى بعضها | تعطيل خيار عزل الأجهزة (AP isolation) إن وُجد في إعدادات نقطة الاتصال |
| الخادم يتوقف عند إطفاء الشاشة | التأكد من تنفيذ `termux-wake-lock`، واستثناء Termux من توفير البطارية |
