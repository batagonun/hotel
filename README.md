# مستودع أدوات الفنادق والنوادي

مستودع يجمع الأدوات الرقمية لدعم التشغيل والتفتيش في الفنادق والنوادي الاجتماعية.

## المشاريع

| المشروع | المسار | الوصف |
|---|---|---|
| تطبيق قوائم التحقق والتفتيش | الجذر (`index.html`، `app.js`...) | تطبيق ويب يعمل على الهاتف دون اتصال، لتنفيذ جولات التفتيش وطباعة التقارير |
| مزامنة Google | [`google-apps-script/`](google-apps-script/) | سكربت يحفظ نتائج التفتيش في Google Sheets |
| مدير أجهزة الواي فاي | [`wifi-manager/`](wifi-manager/) | تطبيق ويندوز يعرض الأجهزة المتصلة بالشبكة |
| مهارات ووكلاء Claude | [`.claude/`](.claude/) | المهارات والوكيل الحارس للمستودع |

## ملفات تطبيق التفتيش
| الملف | الدور |
|---|---|
| `index.html` | صفحة التطبيق |
| `app.js` | المنطق الأساسي |
| `features.js` | المزايا الإضافية |
| `home.js` | الشاشة الرئيسية |
| `seed.js` | البيانات الأولية للقوائم |
| `sync.js` | المزامنة مع Google |
| `sw.js` + `manifest.json` | التشغيل دون اتصال والتثبيت على الهاتف |

## الحوكمة والأمان
- كل تغيير يمر عبر طلب دمج، ولا يُرفع شيء مباشرة إلى `main`.
- يعمل **الوكيل الحارس** تلقائياً مع كل رفع وطلب دمج، ويرسل تقريراً أسبوعياً. التفاصيل في [`SECURITY.md`](SECURITY.md).
- تعليمات الوكيل الحارس لـ Claude في [`.claude/agents/repo-guardian.md`](.claude/agents/repo-guardian.md).
