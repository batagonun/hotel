# مدير أجهزة الواي فاي (نموذج أولي)

تطبيق سطح مكتب لويندوز يعرض الأجهزة المتصلة بالشبكة المنزلية: اسم الجهاز وعنوان IP وعنوان MAC.

## طريقة العمل

1. يحدّد التطبيق شبكة الحاسوب المحلية (مثل `192.168.8.0/24`).
2. يرسل طلب ARP لكل عنوان في الشبكة عبر خدمة ويندوز `SendARP`، على جولتين. الهواتف تتجاهل `ping` غالباً، لكنها تردّ على ARP لأنه شرط لبقائها متصلة.
3. يرسل كذلك `ping` لكل عنوان، ثم يقرأ جدول ARP عبر `arp -a` ليضيف أي جهاز فاته الفحص.
4. يحاول معرفة اسم كل جهاز عبر الاستعلام العكسي عن الاسم (DNS/NetBIOS)، ويعرض "غير معروف" إن لم يتوفر. أسماء الهواتف لا تظهر غالباً.

لا يحتاج التطبيق إلى صلاحيات المدير ولا إلى أي مكتبات خارجية.

## التشغيل على ويندوز

يتطلب Python 3.9 أو أحدث (من python.org، مع تفعيل خيار tcl/tk الافتراضي).

```bat
cd wifi-manager
python main.py
```

يبدأ الفحص تلقائياً عند فتح النافذة، ويمكن إعادته بزر "فحص الشبكة". يستغرق الفحص عادةً من 10 إلى 30 ثانية.

## الاختبارات

```bat
cd wifi-manager
python -m unittest discover tests
```

## إيقاف الاتصال وإعادته

الراوتر المستخدم (Soyealink B311-922 من فودافون) لا يوفّر واجهة برمجية رسمية، لذلك يعمل التطبيق في **وضع العرض فقط**.
زر "فتح صفحة الحظر في الراوتر" يفتح صفحة إدارة الراوتر (`http://192.168.8.1/`) في المتصفح، وإذا كان هناك جهاز محدد في القائمة
ينسخ عنوان MAC الخاص به أولاً، ليلصقه المستخدم في قائمة تصفية MAC داخل صفحة الراوتر.

عند الانتقال لاحقاً إلى راوتر بواجهة رسمية، يُضاف له صنف يرث `RouterAdapter` في `wifi_manager/router.py` ويطبّق
`block(mac)` و`unblock(mac)`.

## قيود معروفة

- يفحص الشبكة بافتراض القناع `/24`، وهو الشائع في الشبكات المنزلية.
- الهاتف في وضع السكون قد يتأخر في الرد؛ إن لم يظهر فافتح شاشته وأعد الفحص.
- إذا كانت ميزة "عزل الأجهزة اللاسلكية" (AP Isolation) مفعّلة في الراوتر فلن يرى الحاسوب أي جهاز لاسلكي آخر.
- كثير من الهواتف تستخدم عنوان MAC عشوائياً (خاصاً) لكل شبكة، وقد يتغير.
