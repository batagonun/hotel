# مدير أجهزة الواي فاي (نموذج أولي)

تطبيق سطح مكتب لويندوز يعرض الأجهزة المتصلة بالشبكة المنزلية: اسم الجهاز وعنوان IP وعنوان MAC.

## طريقة العمل

1. يحدّد التطبيق شبكة الحاسوب المحلية (مثل `192.168.1.0/24`).
2. يرسل طلب `ping` واحداً لكل عنوان في الشبكة حتى يسجّل ويندوز الأجهزة النشطة في جدول ARP.
3. يقرأ جدول ARP عبر الأمر `arp -a` ويستخرج عنوان IP وعنوان MAC لكل جهاز.
4. يحاول معرفة اسم كل جهاز عبر الاستعلام العكسي عن الاسم (DNS/NetBIOS)، ويعرض "غير معروف" إن لم يتوفر.

لا يحتاج التطبيق إلى صلاحيات المدير ولا إلى أي مكتبات خارجية.

## التشغيل على ويندوز

يتطلب Python 3.9 أو أحدث (من python.org، مع تفعيل خيار tcl/tk الافتراضي).

```bat
cd wifi-manager
python main.py
```

يبدأ الفحص تلقائياً عند فتح النافذة، ويمكن إعادته بزر "فحص الشبكة". يستغرق الفحص عادةً من 10 إلى 30 ثانية.

## الاختبارات

```bat
cd wifi-manager
python -m unittest discover tests
```

## إيقاف الاتصال وإعادته

زرّا "إيقاف الاتصال" و"إعادة الاتصال" موجودان في الواجهة، لكنهما يعرضان حالياً رسالة بأن الراوتر غير مُعدّ.
نقطة الربط هي الصنف `RouterAdapter` في `wifi_manager/router.py`: يكفي إنشاء صنف لطراز الراوتر يطبّق الدالتين
`block(mac)` و`unblock(mac)` عبر واجهة الراوتر الرسمية، ثم تمريره إلى `App(router=...)`.

## قيود معروفة

- يفحص الشبكة بافتراض القناع `/24`، وهو الشائع في الشبكات المنزلية.
- الأجهزة التي تتجاهل `ping` قد لا تظهر إن لم تكن قد تواصلت مع الحاسوب مؤخراً.
- كثير من الهواتف تستخدم عنوان MAC عشوائياً (خاصاً) لكل شبكة، وقد يتغير.
